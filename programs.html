Find Your Fit

Which path is right for you?

Both programs start with the fundamentals and build toward practical work. The difference is in the work you'll do — and the problems you'll enjoy solving.

Data Analytics

Turn data into insight.

You'll work with data and extract meaning from it.

  • You enjoy spotting patterns and asking what the numbers tell us.
  • You like spreadsheets, numbers and clear charts.
  • You want to clean, query and visualise real datasets.
Web Development

Turn ideas into experiences.

You'll design and build websites and web applications.

  • You enjoy building things and seeing them work.
  • You care about layout, detail and how a page feels.
  • You want to write code that people can use in a browser.

Whichever path you choose
