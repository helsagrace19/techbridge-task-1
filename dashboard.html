Under the hood

The API behind this dashboard.

Task 7 adds a Node.js and Express API. The dashboard fetches its task data from these endpoints instead of storing it in the page.

GET /api/tasks

Returns all eight internship tasks and their current statuses.

GET /api/tasks/:id

Returns one task for the detail dialog without reloading the page.

PUT /api/tasks/:id

Updates a task status and returns the saved task to the dashboard.

The Express server lives in backend/server.js, with the task data in backend/data/tasks.json. The live deployment exposes the same routes through api/[...path].js. View the server code (opens in a new tab).

React framework

Next.js

Next.js is an open-source React framework for building full-stack web applications. It adds routing, rendering and data fetching on top of React, so a team can build the interface and the server side in one project.

Common uses

  • Marketing sites and content platforms that need fast loads and strong search visibility
  • Full-stack products with server-rendered pages, API routes or server actions
  • React applications that need file-based routing and built-in image optimisation
